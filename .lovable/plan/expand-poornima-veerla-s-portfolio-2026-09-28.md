# Expand Poornima Veerla’s Portfolio

## Goal
Turn the compact first screen into a fuller, more substantial one-page portfolio while preserving its cinematic AI-and-data visual direction.

## What will change
- Increase type scale, content width, spacing, and visual density so the site feels intentional rather than undersized.
- Add Poornima’s verified profile portrait and place LinkedIn, GitHub, and email actions prominently in the introduction and contact areas.
- Expand the introduction with verified location, current degree focus, and professional interests.
- Build deeper sections for skills, education, practical experience, certification, and public projects.
- Link public GitHub projects directly and clearly distinguish confirmed repository work from concept work.
- Preserve the dark, technical aesthetic with cyan data-line details, restrained motion, and strong mobile behavior.
- Add complete page metadata for sharing and search results.

## Verified content sources
- LinkedIn: identity, headline, location, About text, education, and Deloitte Australia Data Analytics Job Simulation.
- GitHub: public profile portrait, account link, repository names, and repository links.
- User-provided: email address and exact LinkedIn/GitHub URLs.

## Content safeguards
- Do not invent employers, dates beyond profile-confirmed education/certification dates, awards, metrics, demos, or project outcomes.
- Use careful wording for repositories with limited descriptions.
- Keep future or unverified achievements out of the page rather than showing placeholder sections.

## Technical details
- Rebuild the existing single page at `/` in the current TanStack app.
- Define the complete visual system in shared semantic design tokens.
- Store the verified portrait as a project asset rather than relying on a hotlinked image.
- Verify the finished page at desktop and mobile sizes, including all contact and project links.
